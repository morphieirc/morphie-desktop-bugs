# Morphie Desktop Bug Tracker

This is the public bug tracker for **Morphie Desktop Client**.

Use this repository to report reproducible problems with the desktop IRC client. Please search existing issues before opening a new report.

## What to include

A useful report should include:
- Morphie Desktop Client version
- operating system
- what happened
- steps to reproduce the problem
- what you expected to happen
- screenshots when they help explain the problem

## Privacy and security

**Do not post sensitive information in a bug report.** This repository is public.

Never include:
- account passwords
- NickServ passwords
- IRC operator passwords
- private-message contents
- private chat logs
- access tokens or API keys
- personal information you do not want publicly visible

The in-client **Help → Report a Bug** form is designed to include only basic, non-sensitive diagnostics.

For general Morphie help, visit https://morphie.com/help.
